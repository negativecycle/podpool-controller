Replica distribution

One call to the distributor, with every constraint combination the CRD admits. Set a pool size and each group's (min, target, max) triple and read back the split the controller would compute. The JavaScript is a transliteration of workload.ComputeGroupTargets, checked against the Go tests' own fixture rows every time this page loads — the badge says so. There is no clock here: a walk-up, a backoff and a runaway are properties of a sequence, which is what Sim 2 is for.
